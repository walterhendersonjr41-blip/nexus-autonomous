# NEXUS Autonomous

A one-page mobile dashboard for self-running multi-agent operations.

This is a **demo**. The accuracy ring, agent percentages, and insights are sample data, not live metrics. There is no backend, tracking, or external scripts.

Open the page in a browser, or add it to your phone’s home screen from the share / install menu.

Live: https://walterhendersonjr41-blip.github.io/nexus-autonomous/
